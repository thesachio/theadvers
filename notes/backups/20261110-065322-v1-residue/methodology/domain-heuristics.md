# DOMAIN-HEURISTICS — Jembatan Kompatibilitas ke Router Plugin Domain (theadvers v2.0)

> PEMBERITAHUAN ARSITEKTUR MODULAR v2.0 (`1 FILE = 1 DOMAIN`):
> Heuristik pengetahuan domain kini menggunakan arsitektur Drop-in Plugin di dalam direktori methodology/domains/.
> - Untuk melihat indeks ringkas seluruh domain (DOM-*) beserta Trigger Symptom-nya, baca: `methodology/domains/_ROUTER.md`.
> - Untuk menambah atau merevisi heuristik domain, buat atau ubah berkas mandiri methodology/domains/DOM-<slug>.md lalu jalankan python3 tools/verify_segitiga.py --sync.
> - Dilarang memuat seluruh berkas domain sekaligus ke dalam memori; gunakan _ROUTER.md untuk *lazy-loading* hanya domain yang sesuai dengan Wilayah Aktif R_i.
